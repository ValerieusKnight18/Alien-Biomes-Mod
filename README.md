Alien Biomes is a Minecraft Mod for Minecraft Version 1.21.1, using the NeoForge modloader.

As its name suggests, Alien Biomes adds several new and unique biomes to Minecraft, with a sci-fi or otherworldly theme.

v0.1 adds:

Sky Asteroid biome
- generates above y=256
- contains many small asteroids
- asteroids can be Stony, Icy, Metallic, or Carbonaceous

This mod was designed for the 2025 CurseForge Minecraft ModJam, by ValerieusKnight18
